# ALPACART — Página Institucional

Sitio web corporativo de la marca premium de alpaca peruana.

## Rutas

| Ruta | Página |
|---|---|
| `/` | Inicio |
| `/about` | Nosotros |
| `/catalogo` | Catálogo |
| `/promociones` | Promociones |
| `/preguntas` | FAQ |
| `/terminos` | Términos y Condiciones |
| `/politicas` | Políticas de Privacidad |
| `/contacto` | Contacto |

## Scripts

```bash
npm run dev      # http://localhost:3101
npm run build
npm run preview
```

## Stack
- React 19 + Vite 6
- CSS Modules
- Tema claro/oscuro
